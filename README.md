Diwali Sales Data Analysis (EDA)

📌 Project Overview

This project focuses on Exploratory Data Analysis (EDA) of Diwali sales data using Python. The objective is to analyze customer purchasing behavior, understand sales patterns, and identify customer segments and product categories that contribute to sales.

The analysis uses data cleaning, grouping, statistical summaries, and data visualization to explore the dataset and discover meaningful insights.

🎯 Project Objectives

Analyze customer demographics based on gender and age group.
Compare purchasing amounts across gender and age groups.
Identify the states with the highest number of orders and sales amounts.
Analyze customer purchasing behavior by marital status and occupation.
Explore product categories based on customer orders and sales.
Identify the most frequently ordered products.
Generate insights that can support business and marketing decisions.

🛠️ Technologies Used
Python – Data analysis and programming
Pandas – Data cleaning, manipulation, and aggregation
NumPy – Numerical operations
Matplotlib – Data visualization
Seaborn – Statistical charts and visual analysis
Jupyter Notebook – Interactive analysis and documentation

🔍 Project Workflow

Data Loading: Imported the Diwali sales dataset into a Pandas DataFrame.
Data Inspection: Examined the dataset structure, columns, data types, and missing values.
Data Cleaning: Removed unnecessary columns, handled missing values, and converted the Amount column to an integer.
Exploratory Data Analysis: Analyzed customer demographics, state-wise sales, occupations, and product categories.
Data Visualization: Created count plots and bar charts using Matplotlib and Seaborn.
Insights and Conclusion: Summarized purchasing patterns observed in the dataset.

📊 Analysis Performed

Top 10 products based on orders

💡 Key Insights

Based on the conclusion recorded in the notebook:
Customers in the 26–35 age group are highlighted as an important purchasing segment.
Married women are identified as a notable customer segment.
Uttar Pradesh, Maharashtra, and Karnataka are highlighted in the analysis.
Customers working in IT, Healthcare, and Aviation are identified in the notebook's conclusion.
Food, Clothing, and Electronics are highlighted as important product categories.

These are observations from the notebook's analysis and should be validated against the underlying data before being used for business decisions.
